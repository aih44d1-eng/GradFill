What it does

One profile. Everything else gets easier from there.

We built GradFill because filling in the tenth near-identical application of the week isn't how anyone wants to spend an evening. Save your details once — GradFill handles the repetition, and you stay in charge of everything that actually goes out the door.

✓

Autofill from one profile

Save your education, experience, skills, contact details and preferences once. From then on, GradFill fills them in for you across application pages — no more hunting down the same answer for the fifth time this week.

?

Honest about what it isn't sure of

If GradFill can't confidently fill a field, it says so rather than guessing or leaving it silently blank — flagged clearly, so you always know what's worth a second look before you submit.

AI

AI-drafted written answers

Stuck on how to answer "why this role?" again? Ask for a draft, read it over inside GradFill, and edit it until it sounds like you. Nothing is written or submitted without you choosing to.

AI

Resume Studio

Ask for a resume tailored to a specific role, built only from facts already in your saved profile — reordered and emphasised for the job, never invented. Keep as many versions as you like.

✓

Job Tracker

Every application in one place: Saved → Applying → Applied → Assessment → Interview → Offer, with notes, links, the job description you saved, and which resume version you used.

✓

You press Submit — not GradFill

GradFill fills things in and helps you draft. It will never click Submit on your behalf. You always get the final look before anything goes anywhere.

Pricing

The free part isn't a trial — it's the whole autofill engine.

Autofill, the Job Tracker, and your saved profile cost nothing to run and are never gated, so they're free with no limit, no trial period, no catch. Only the generative AI features — written-answer drafts, resume tailoring, cover letters — are metered and need Pro or a Season Pass, because those are the parts that cost us real money to run.

Where this stands today

This is early, on purpose

GradFill AI is genuinely early. The autofill engine and Job Tracker are solid and free forever — that part isn't going anywhere. The AI drafting is real too: it's live, it's careful about only using facts you've actually given it, and you can see exactly what's built by looking at the code itself, which is public.

Some things aren't finished. Avature autofill is detection-only right now. There's no Chrome Web Store listing yet. We'd rather tell you that plainly than dress it up — and we'd rather earn your trust with real reviews once there are real users, instead of putting invented quotes on this page today.
